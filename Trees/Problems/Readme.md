## Notes

    1.Tree is a form of graph
        a. n vertices
        b. n-1 edges
        c. acyclic
        d. unique path from one vertex to another
        e. connected (whole tree is a connected component)
        f. exactly one parent except root

    if any of 2 conditions in b,c,e are true it is a tree
